Where do I get more avatars?

Extra avatar presets from the LiteAvatar Gallery can be dropped into the data/Avatars_2D/ folder as a subfolder containing net_encode.pt, net_decode.pt, bg_video.mp4 and the rest of the preset files — they'll show up here automatically next time this page loads. If you've downloaded the gallery's 20250408/20250612 zip folders, use the Import new avatars button in the right panel instead of doing this by hand.

How do the Ethnicity/Gender filters work?

Unlike the 3D avatars, there's no way to automatically detect these from a LiteAvatar model folder - it's just neural network weights and a background video, no such metadata exists in it. To tag an avatar, add a meta.json file next to its folder (e.g. data/Avatars_2D/avatar_03/meta.json):

{"gender": "female", "ethnicity": ""}

Leave a field blank and it just won't appear in that filter.
